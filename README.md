# AV Engineering Suite

A web-based engineering toolkit for AV System Integrators and Presales Engineers.
Built to simplify calculations and planning for:
- 📺 LCD Video Wall Calculator
- 🖥️ LED Display Calculator
- 🏢 Meeting Room Sizing
- 🎛️ Video Processor Planner
- 🔌 Rack & Power Calculator
- 📋 Project Bill of Materials (BOM)
---
## Features
### LCD Video Wall
- Display sizing calculator
- Resolution calculator
- Bezel compensation
- Aspect ratio recommendation
- Processor requirement estimation

### LED Display
- Quick sizing
- Cabinet planner
- Processor calculator
- Power calculator
- Cabinet visualization
- Pixel pitch recommendation
- Installation insights

## Why This Project?
This project was created because many AV engineering calculations are still done manually using spreadsheets.
The goal is to provide a fast, visual, and engineering-friendly platform that helps:

- System Integrators
- Presales Engineers
- Consultants
- Project Managers
- Technical Sales Teams
